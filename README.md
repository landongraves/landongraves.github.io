# landongraves.github.io

Personal website for Landon Graves, hosted with GitHub Pages.

## Local development

```bash
npm install
npm run dev
```

Open <http://localhost:8000>. The personal homepage is served at `/`, and the OSINT Framework project is available at `/public/` locally and `/framework/` in production.

## Deployment

Pushes to `main` deploy automatically through the GitHub Pages workflow in `.github/workflows/pages.yml`.
